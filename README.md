# 手势放映室 · Gesture Studio

项目网址（发布完成后可访问）：https://kevin-sc30.github.io/gesture-studio/


打开摄像头，用手势触发爱心、气球、彩纸、烟花等特效。支持手机和电脑，可手动点击卡片预览，也可切换镜像、骨架、音效、全屏和拍照保存。

| 手势 | 特效 |
| --- | --- |
| 双手比心 | 爱意满屏 |
| 单手比耶 | 气球 |
| 单手点赞 | 点赞与星星 |
| 双手比耶 | 彩纸 |
| 双手点赞 | 烟花 |
| 单手倒赞 | 下雨 |
| 伸出拇指、食指和小指 | 激光 |
| 张开手掌 | 星光 |

保持手势约 1 秒。触发后放下手，再重新摆出手势。

## 运行

通过 GitHub Pages 发布 `master` 分支的根目录，更新分支后会自动重新部署。摄像头需要 HTTPS 和用户授权，识别需要浏览器支持 WebAssembly 与 WebGL。手机推荐用系统 Safari 或 Chrome 打开。

识别在设备本地进行，摄像头画面不上传，不申请麦克风权限。MediaPipe 运行时、WASM 和模型随网页一起托管，无需第三方 CDN。首次开启摄像头约需加载 20 MB 资源。

## 验证范围

已检查手机与桌面布局、8 种特效预览、音效、PNG 导出、手势映射和触发稳定器。远程测试环境缺少可用 WebGL，尚未完成真实摄像头的端到端测试，双手比心识别需在目标设备上试用。
